# matrix-lab

一个用于线性代数学习的中文矩阵计算工具，支持计算矩阵的**行简化梯形阵（行最简形）**和**列简化梯形阵（列最简形）**，并逐步展示初等变换过程。

希望通过这个工具，让矩阵计算更方便，也让每一步变换更容易理解。

## 项目功能

- **行简化**：通过初等行变换计算行最简形。
- **列简化**：通过初等列变换计算列最简形。
- **自定义矩阵**：支持 1～10 行、1～10 列的矩阵。
- **多种数值输入**：支持整数、小数和分数，例如 `-2`、`0.5`、`1/3`。
- **精确分数计算**：使用有理数运算，避免浮点数舍入误差。
- **变换过程展示**：可以逐步查看，也可以展开全部步骤。
- **矩阵秩**：计算并显示矩阵的秩 `r(A)`。
- **快捷操作**：支持粘贴矩阵、复制结果、载入示例和清空输入。
- **响应式布局**：适配电脑和手机屏幕。

## 使用方法

1. 选择“行简化”或“列简化”。
2. 输入行数和列数，点击“更新矩阵”。
3. 填写矩阵元素，也可以通过“粘贴矩阵”批量输入。
4. 点击“开始简化”。
5. 查看最终结果，并通过“逐步推导”或“全部步骤”学习变换过程。
